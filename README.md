## Overview

This portfolio presents the work of **Afia Tasnim Ria**, a Computer Science & Engineering undergraduate at **United International University**. It brings together full-stack web applications, Java desktop systems, healthcare UX concepts, IoT prototypes, and research in medical AI.

The site uses a dark visual language with green accents, editorial typography, animated interface details, and a responsive layout.

## Features

- **Responsive landing page** with an animated orbit displaying core technologies
- **Floating navigation** with mobile menu and section links
- **About and academics** sections with a results timeline
- **Research showcase** for medical image classification and survival prediction
- **Project gallery** with descriptions, technical tags, and repository links
- **Skills and experience** sections
- **Contact area** with social links and a message form interface
- **SEO foundations** including metadata, canonical URL, Open Graph tags, and JSON-LD structured data
- **Accessibility considerations** including a skip link, semantic sections, labels, and ARIA attributes

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/afiatasnimria/YOUR-PORTFOLIO-REPOSITORY.git
cd YOUR-PORTFOLIO-REPOSITORY
```

Replace `YOUR-PORTFOLIO-REPOSITORY` with the actual repository name.

### 2. Check the files

The supplied HTML references these assets:

```text
portfolio/
├── index.html
├── style.css
├── script.js
├── Afia-CV.pdf
├── robots.txt        # optional, if configured
├── sitemap.xml       # optional, if configured
└── README.md
```

Make sure `style.css`, `script.js`, and `Afia-CV.pdf` exist alongside `index.html` and that their names match the references in the HTML.

### 3. Run locally

Open `index.html` in a browser, or use a local development server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment

Because this is a static website, it can be deployed to Vercel, Netlify, or GitHub Pages without a framework build command.

**Before publishing:**

1. Replace the placeholder domain `https://afia-portfolio.vercel.app/` with the real deployed URL in the canonical tag, Open Graph URL, and JSON-LD data.
2. Update `sitemap.xml` and `robots.txt` if those files are included.
3. Ensure the CV PDF and all linked assets are available.
4. Add an actual social preview image and corresponding `og:image` / `twitter:image` tags if desired.
5. Test the contact form end-to-end. The supplied HTML defines its interface, but successful message delivery depends on the JavaScript implementation or a configured backend service.
